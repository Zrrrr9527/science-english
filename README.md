## 四页分工

- **知识体系**：科学概念、术语边界、模型适用条件。
- **教学标准**：指令动词释义、AO 归组、答题要求。
- **映射清单**：逐项核对前两页是否在说同一件事。
- **范文与例句**：把前两页的规则变成可照着写的英文。

冲突时的裁决顺序：科学概念 → 知识体系；指令动词与答题要求 → 教学标准；范文与例句只负责「怎么表达」，不得反向修改前两页。

## 来源性质

四页内容分三类标注：**有出处的规范描述**（给出学科、版本、首考年份、页码）、**通行惯例**（课堂与教材常见做法，非硬性规定）、**本体系自建的教学分类**（四认知梯度、九个功能模块、失分八型等，非 IB 官方）。

未取得原文的项目一律标 **PENDING**；没有标注的内容不得引作 IB 官方要求。
